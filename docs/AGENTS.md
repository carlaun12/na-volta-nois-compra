# Orientações para agentes

## Contexto

O repositório `na-volta-nois-compra` contém uma base Kotlin Multiplatform para
Android e Linux Desktop JVM. Consulte o `README.md` para estrutura e comandos,
o `AGENTS.md` da raiz para regras de desenvolvimento e `docs/VALIDACAO.md`
para os resultados das verificações.

## Documentação

- Escreva em português e use Markdown.
- Mantenha as instruções claras, objetivas e atualizadas.
- Documente configurações e comandos apenas quando estiverem implementados.
- Use caminhos relativos ao repositório ao referenciar arquivos.
- Não inclua senhas, tokens ou outros dados sensíveis.

## Alterações

- Leia os arquivos relacionados antes de fazer alterações.
- Preserve o trabalho existente e a licença do projeto.
- Mantenha as mudanças alinhadas ao pedido do usuário.
- Confira os links, os caminhos e a formatação dos documentos alterados.
